Part 1: Project Architecture Setup

shopping-mall/
├── backend/
│   ├── Dockerfile
│   ├── server.js
│   └── package.json
└── frontend/
    ├── Dockerfile
    ├── nginx.conf
    ├── index.html
    ├── package.json
    ├── tailwind.config.js
    ├── postcss.config.js
    ├── vite.config.js
